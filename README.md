# ECommerceGPT – AI-Powered E-Commerce Chatbot using Ollama

A modular Retrieval-Augmented Generation (RAG) based e-commerce chatbot built with **Ollama** (`qwen2.5:0.5b` and `nomic-embed-text`), **scikit-learn**, **pandas**, and pre-trained sentiment analysis (**NLTK VADER / TextBlob**).

---

## 🏛️ System Architecture

```text
                                User Query
                                    │
                                    ▼
                          Intent Detection (Ollama)
                                    │
       ┌────────────────────┬───────┴────────────┬────────────────────┐
       ▼                    ▼                    ▼                    ▼
     [ FAQ ]        [ RECOMMENDATION ]      [ PRODUCT ]           [ REVIEW ]
       │                    │                    │                    │
  Dense Vectors        TF-IDF Catalog       Constrained RAG      Pre-trained
  (nomic-embed)         Search & Top-3       Factual Context      Sentiment Model
  Cosine Similarity       Rank (Budget)       (Multi-turn)        (VADER / TextBlob)
       └────────────────────┼────────────────────┴────────────────────┘
                            │
                            ▼
                     Ollama (Qwen2.5)
                            │
                            ▼
                Natural Language Response
```

## 📁 Project Directory Structure

```text
ECommerceGPT/
├── app.py                    # Web Dashboard Studio (Streamlit)
├── chatbot.py                # Continuous interactive console chatbot
├── create_embeddings.py      # Q3: Generates and stores 768-d FAQ embeddings (nomic-embed-text)
├── faq_module.py             # Q4-Q5: Semantic FAQ cosine search & threshold routing
├── recommendation_module.py  # Q6-Q7: TF-IDF product retrieval & Ollama justified recommendation
├── product_module.py         # Q8-Q9: Structured context RAG & constrained product Q&A
├── review_module.py          # Q10-Q11: Pre-trained sentiment analysis & Ollama review synthesis
├── intent_module.py          # Q12: Intent classification with few-shot validation
├── part_a_dataset_prep.py    # Q1-Q2: Dataset inspection & schema exploration
├── data_utils.py             # Robust dataset loader & schema cleaner
├── ollama_client.py          # Unified Ollama daemon connection & model health wrapper
├── verify_all_modules.py     # Automated test suite covering all 13 requirements
├── requirements.txt          # Python dependency specifications
├── data/
│   ├── products.csv          # 100 products (ProductID, Name, Category, Brand, Price, Rating, Description)
│   ├── faqs.csv              # 20 store FAQs (FAQID, Question, Answer)
│   └── reviews.csv           # 1,000 verified customer reviews (ReviewID, ProductID, ProductName, Review, Rating)
└── models/
    ├── faq_embeddings.npy    # Dense embeddings generated by nomic-embed-text (20 x 768)
    ├── faq_tfidf.pkl         # Fallback TF-IDF vectorizer and sparse matrix
    └── faq_data.pkl          # Cached FAQ dataframe
```

## ⚡ Prerequisites & Setup

### 1. Ollama Installation & Model Pulling
Ensure [Ollama](https://ollama.ai) is installed and the required models are pulled:
```powershell
ollama pull qwen2.5:0.5b
ollama pull nomic-embed-text
```

### 2. Python Environment & Dependencies
Install dependencies using PowerShell:
```powershell
pip install -r requirements.txt
```

---

## 🚀 Execution Commands

### 1. Run Complete Automated Test Suite (All 13 Requirements + 9 Queries)
```powershell
python verify_all_modules.py
```

### 2. Launch Modern Web Dashboard (Recommended for Demonstration)
```powershell
python -m streamlit run app.py
```
*Accessible in your browser at `http://localhost:8501`.*

### 3. Run Interactive Console Chatbot
```powershell
python chatbot.py
```
*(Type `exit` or `quit` to terminate).*

### 4. Run Individual Modules
```powershell
# Part A: Dataset Inspection & Schema
python part_a_dataset_prep.py

# Part B: Build Embeddings & Test Semantic Search
python create_embeddings.py
python faq_module.py

# Part C: Product Recommendation Engine
python recommendation_module.py

# Part D: Product QA RAG (Multi-turn)
python product_module.py

# Part E: Customer Review Sentiment
python review_module.py

# Part F: Intent Detection
python intent_module.py
```
